# 家電チェッカー Web 版

家電の写真や品番から、発売日・使った年数・取扱説明書を調べるページです（iPhone・iPad・Android・パソコンのブラウザで使えます）。

- ページ: https://chocorin0000.github.io/kaden-checker/
- 調べる処理は、使う人それぞれの Google Apps Script（Gemini の API キーと合言葉はそちらに置く）で動きます。
  このリポジトリには、スクリプトの URL・合言葉・API キーは入っていません。
- 「ホーム画面に追加」すると、アプリのように使えます。電波がないときや、サーバーから読めないときは、前に覚えた版で開きます。
